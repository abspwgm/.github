# Support

| You want to | Go here |
|---|---|
| Chat, or ask a quick question | [Discord](https://discord.gg/ufC2RFxxkx) — the fastest route for anything that is not yet a bug report |
| Report a bug | Issues on the affected repository |
| Ask how something works | Issues on the affected repository, or the docs in that repo |
| Report a security problem | **Report a vulnerability** on that repository's Security tab — see [SECURITY.md](SECURITY.md) |
| Run a server | [The fleet board](https://abspwgm.github.io/absolute-game-servers/) lists what is live, and each image's README has its compose file |
| Propose a new game | Open a [new-game issue](https://github.com/abspwgm/.github/issues/new?template=new_game.yml) — the registry entry comes first, the image second |

This is a small operation. Issues are read, and a question that turns out to be
a documentation gap is closed by fixing the documentation.
